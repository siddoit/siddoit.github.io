EduBot — Interactive Educational Robot

A Raspberry Pi 5 robot that talks, listens, and recognises students — with bilingual English and Malayalam learning workflows.

View on GitHub

Overview

EduBot is an AI-powered educational robot built on a Raspberry Pi 5. It holds conversations with primary-school students using a large language model, understands them through speech-to-text, and replies with natural text-to-speech — no keyboard required.

Vision & Identity

AWS Rekognition handles vision-based student identification, so the robot can greet returning students by name. A custom administration interface lets teachers manage rosters and track sessions.

Bilingual by Design

Learning workflows are designed in both English and Malayalam, letting the robot switch languages mid-conversation for interactive, locally relevant primary-school lessons.
