IoT Smart Medicine Dispenser

Automated medication management system with servo dispensers and remote caregiver dashboard

View on GitHub

Overview

An automated medication management system designed to improve dosage adherence for patients who require regular medication. ESP32 microcontrollers drive servo-actuated dispensers that release the correct medication at programmed times — removing the need for manual intervention and reducing the risk of missed or incorrect doses.

Remote Dashboard

A web-based caregiver dashboard provides full remote control and monitoring without requiring physical access to the device. Caregivers can:

  • Monitor dosage adherence in real time
  • Receive instant alerts when a scheduled dose is missed
  • Modify dispense schedules remotely at any time

Tech Stack
