Embodied Semantic Asset Recall Robot

A fully offline autonomous mobile robot that finds objects from natural-language queries, built on Jetson Orin Nano and ROS 2.

View on GitHub

Overview

An autonomous mobile robot that retrieves physical objects on command — you ask for "the red toolbox from last week" and it goes and finds it. Everything runs offline on an NVIDIA Jetson Orin Nano with ROS 2, Nav2, and ARCore-based visual-inertial odometry. No cloud, no LiDAR, no dedicated depth camera.

Semantic Memory

The robot builds a persistent, open-vocabulary 3D scene graph of its environment. Objects are detected and labelled with YOLO-World, Florence-2, and CLIP embeddings, so it can answer natural-language queries about what it has seen and where.

Active Search

When an object has been moved, a Bayesian belief model drives active search — prioritising where the item is most likely to be rather than scanning blindly. This keeps the robot useful in messy, changing spaces without any cloud service.
