Intelligent Document Automation

AI-powered 3-way matching of supply-chain documents using YOLOv8 and Gemini API

View GitHub Profile

Overview

Built at Innovizta (Campus Startup internship). This system automates the verification of scanned supply-chain documents via 3-way matching — cross-referencing Purchase Orders (PO), Delivery Notes, and Invoices to confirm consistency and flag discrepancies without human review.

How It Works

The pipeline combines two complementary AI systems:

  • YOLOv8 handles document layout detection and structured field extraction from scanned PDFs and images — identifying regions such as item lines, totals, dates, and vendor information.
  • Gemini API applies LLM reasoning to cross-reference extracted fields across all three document types, catching contextual mismatches (e.g., quantity discrepancies, vendor name variations, or unit price inconsistencies) that deterministic rule-based systems routinely miss.

Impact

Significantly reduces the manual effort required for supply-chain document verification. By combining object detection for extraction accuracy with LLM reasoning for contextual understanding, the system catches a broader class of errors than traditional rule-based approaches — improving both speed and reliability of the verification process.
