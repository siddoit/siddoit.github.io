Autonomous Vehicle Research Platform

Cost-effective ADAS system using a Samsung Galaxy S23 as the primary edge compute unit.

Ongoing Edge AI Research

Overview

This research project explores a cost-effective approach to Advanced Driver Assistance Systems (ADAS) by repurposing a Samsung Galaxy S23 as the primary edge compute unit for autonomous navigation. The core thesis: capable autonomous navigation doesn't require expensive dedicated hardware — modern flagship smartphones carry NPUs powerful enough for real-time inference.

What I'm Building

  • Quantizing and optimizing YOLO-based object detection models for NPU deployment via TFLite, minimizing inference latency on mobile silicon.
  • Developing synthetic training environments in NVIDIA Isaac Sim to generate diverse driving scenarios for sim-to-real transfer of driving policies.
  • Architecting sensor fusion pipelines combining the phone's camera and IMU data for robust perception.
  • Evaluating INT8 and FP16 quantization strategies and their accuracy/latency trade-offs on mobile NPUs.

Technical Highlights

  • TFLite Model Quantization — INT8/FP16 post-training quantization for NPU acceleration
  • NVIDIA Isaac Sim — Synthetic dataset generation for diverse driving conditions
  • Sim-to-Real Transfer — Domain randomization techniques to bridge the simulation gap
  • Android Integration — Camera2 API + IMU sensor fusion on Android

Stack

TFLite · NVIDIA Isaac Sim · Android (Camera2 API) · Python · C++ · OpenCV · YOLO
