6-Node Distributed Environmental Sensor Network

Campus-wide IoT sensor network monitoring air quality, temperature, humidity and particulate matter

View on GitHub

Overview

Engineered a scalable 6-node distributed environmental sensor network as part of the ICCC Saintgits Taiwan–India Collaboration. Physical sensor nodes are deployed across campus, each continuously transmitting real-time environmental measurements to a central server for aggregation, validation, and historical logging.

Firmware & Sensors

Each node is powered by a NodeMCU ESP32S microcontroller interfacing with a suite of environmental sensors:

  • AHT10 — temperature and humidity
  • HL83 — rain detection
  • SDS011 — PM2.5 and PM10 particulate matter

Data Validation

Integrated the Open-Meteo and OGD India REST APIs to create virtual reference nodes. These API-sourced readings serve as ground-truth comparators, automatically validating physical sensor readings and flagging anomalous or faulty data points.

Communications

MQTT is used as the telemetry protocol for low-latency, lightweight message delivery from each sensor node. A Python multi-threaded backend synchronises asynchronous API calls with high-frequency sensor data streams, ensuring consistency across all data sources.

Backend & Storage

Server-side scripts parse incoming JSON payloads from MQTT and automatically generate structured MySQL logs. This provides a full historical record for trend analysis, anomaly detection, and reporting.

Tech Stack
