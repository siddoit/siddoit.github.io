NeuraHome — LLM-Driven Smart Home

Gesture and voice-controlled home automation built during the Srishti 2025 hackathon

View on GitHub

Overview

Built during the Srishti 2025 4-day rapid prototyping hackathon. I led the Hardware & Circuit team of 5. NeuraHome is an LLM-powered home automation system that accepts both gesture and natural language voice commands to control real electrical loads — no dedicated app or remote required.

Gesture Control

MediaPipe's hand-tracking model continuously monitors a webcam feed, recognising predefined gestures to trigger device actions touchlessly. This provides an intuitive, zero-latency control method for users in the same room as the device.

Voice & LLM Control

The Gemini API processes natural language voice commands, enabling conversational device control. Users can issue complex, contextual commands (e.g., "turn off all lights except the bedroom") which the LLM interprets and maps to the appropriate hardware actions.

Hardware

ESP32-based relay modules actuate real electrical loads based on commands received from either the gesture or voice interface. The hardware layer is intentionally decoupled from the control software, making it straightforward to extend with additional relays or sensor inputs.

Cloud Sync

Firebase Realtime Database keeps all three interfaces — gesture control, voice/LLM control, and the web dashboard — in sync. Any state change from any interface is immediately reflected across all others, ensuring a consistent view of the home's device states.

Tech Stack

MediaPipe Gemini API ESP32 Firebase Python JavaScript
