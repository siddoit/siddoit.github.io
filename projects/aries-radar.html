Aries Radar System

Real-time browser-based hand-tracking radar built with Flask, MediaPipe and HTML5 Canvas

View on GitHub

Overview

Migrated a legacy Tkinter desktop radar visualizer to a full-stack web application built with Flask and HTML5 Canvas. The new system runs entirely in the browser with no installation required, making it immediately accessible to any user with a webcam and a modern browser.

How It Works

MediaPipe's hand landmark model detects hand keypoints via the device webcam in real time. A Flask backend receives and streams this landmark data to the browser using WebSockets/SSE. On the client side, an HTML5 Canvas renderer draws the radar display, plotting hand position as a sweeping blip on a circular grid — replicating the classic radar aesthetic with modern web technology.

Key Achievement

Achieved sub-50 ms end-to-end latency between a physical hand movement and its corresponding visual update on the radar display — a critical benchmark for any real-time interactive system.
